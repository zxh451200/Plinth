复合控件允许焦点落在模板子控件中，但必须由真实 Tab 输入到达；测试只对导航起点调用 `Focus()`。遍历最多 256 次，未达目标即失败，不以直接聚焦目标伪装键盘验证。禁用或隐藏控件不属于当前状态的遍历目标；按 `TemplatedParent` 排除滚动条等模板内部按钮，并将复合控件内部输入归属外层控件。表格名称检查不代表表格单元格的读屏与方向键行为已经验证。

类型化单元格（2026-11-08 起）：Demo 的数量、截止日期、优先级、启用四列在选中行内分别渲染 `NumericUpDown`／`DateField`／`ComboBox`／`CheckBox`，未选中行只读。Windows 实测需覆盖数量越界与小数输入、日期弹层在表格内的定位与清除、枚举下拉键盘选择、布尔切换、三档密度与中英文、Esc／取消丢弃草稿、保存失败保留草稿、切换行／分页／搜索后的草稿规则，以及读屏名称与焦点顺序。`DemoTypedInlineEditingTests` 只证明控件树、草稿与校验接线，不证明真实弹层、IME 与读屏。

尺寸测试在本文件中独立设置窗口宽高并执行 Measure/Arrange，因为已有 `Shell.Layout()` 固定 1200×720。测试中的窗口尺寸是 DIP，不是 Windows 显示缩放或物理像素。几何断言只检查所列目标边界，不能证明所有文本未截断、所有兄弟元素未重叠或实际绘制未被祖先裁剪。

## Windows 实测矩阵

列宽调整回归：表格现允许拖动列头边界，拖拽把手不绘制竖线但保留命中区。`DemoListPreferencesTests.Pointer_resizing_a_column_is_saved_and_restored_in_a_new_view` 使用窗口指针输入而非直接设置 Width，核对宽度变化、保存及新视图恢复；本轮尚未编译运行。Windows 实测还需核对边界光标、100/125/150/200% DPI 下的拖拽、列隐藏／显示、恢复默认及偏好写入失败提示。

列表偏好需核对搜索词、分页大小、排序和列宽／显隐在重开后恢复。“恢复列表默认值”取消未保存确认时保留草稿及原偏好；允许后恢复空搜索、第一页、50 条、编码升序及全部列默认宽度，列菜单勾选同步。偏好文件无法写入时必须提示，旧文件不变，恢复可写后可再次保存。切换标签期间恢复默认后，切回的视图不能显示旧列布局。`DemoListPreferencesTests` 包含 8 个参数场景源码，其中视图场景检查命令绑定与布局属性，未模拟真实鼠标点击；当前没有 C# 或 Windows 验收证据。

更新入口需单独验收：默认不联网；手动检查发现新版本后显示地址和“打开下载地址”，只在点击时调用默认浏览器。无默认浏览器或启动失败时显示安全提示，可重试。重新检查开始即撤下旧入口，失败／已最新／未配置时保持隐藏；非法协议、含账号或片段的地址不得打开。检查挂起时关闭关于页，旧结果不得回填或恢复按钮，重开得到新页面。`AboutUpdateTests` 提供 11 个参数场景源码，当前没有 C# 或真实浏览器验收证据。

使用产品支持的 Windows 版本，至少 Windows 11；如宣称支持 Windows 10，补测其受支持版本。使用干净的测试数据目录，记录应用版本、提交标识或源码归档校验、Windows 版本、.NET 版本、主题、字体、屏幕分辨率、缩放、语言和测试者。切换语言后界面应立即切换（含已打开页面、导航和状态栏），不需要重启。

## 固定详情与任务面板

CSV 结果需核对成功新增／更新数量与实际数据库一致，导出行数与文件一致；同一行多个错误只计一行，达到错误限额显示“至少”，数据库失败或无法判断时显示“未知”。关闭业务页后任务中心仍保留摘要及纯文本文件位置，重试使用新结果；提交前取消不得发布成功结果，已提交后迟到取消不得冒充回滚。检查结果不进入任务日志或诊断包。读取进度按每遍文件字节重新开始，导出按同一读取事务的总行数计算，未知阶段不显示伪造百分比。`TaskOutcomeTests`／`CsvTaskOutcomeTests` 为回归源码，尚未执行。

将预览错误报告保存到用户选择的其他目录，核对成功后任务中心及完成提示显示该实际路径和问题条数，不显示业务错误正文；默认 CSV 导出仍位于 exports。相对路径、控制字符、格式扩展名不符、超长路径或符号链接不能进入任务结果。此处路径显示是纯文本，不自动访问、打开或上传文件。

在显式启用 XLSX 的验收构建中，确认导入后关闭标签，任务中心应保留新增／更新计数；业务拒绝显示整批零提交、准确的已发现错误行数及报告位置，内外两层审计均为 rejected。导出到自选目录后关页，核对实际 `.xlsx` 行数和任务路径一致；预览不冒充已提交。排队取消不得产生结果，提交完成后的迟到取消保留成功；生产导入和导出分别只确认一次，拒绝确认或授权不得产生成功结果。加载比例按实际行数，转换及 ClosedXML 保存不显示伪造百分比。新增 `SpreadsheetPageTests` 为测试源码，尚未执行；功能仍受 XLSX POC 门槛约束。

XLSX 确认导入等待授权或生产确认时，把中转 CSV 替换为另一份结构及业务字段均合法的 CSV，必须拒绝且零入库；不能只用损坏文件验证内容绑定。数据库执行失败另检查整批回滚，无法定位失败行时显示未知，不伪造错误报告。

XLSX 文件或目录选择器打开期间，分别关闭页面、切换上下文、隐藏宿主和脱离后重挂视图；迟到路径或异常不得启动预览／导出或更新旧页。两个选择按钮交叉点击只保留一次选择操作，取消或失败后可重试，已入队后关页继续执行。`SpreadsheetPickerLifetimeTests` 为受控选择器回归源码，不能替代原生选择器实测。

设置页健康检查等待期间修改地址、路径或启用状态，旧请求的成功、失败、异常及取消都不得覆盖当前配置状态；新检查先结束后，旧检查不能回填。授权保存等待或拒绝回填时，不把尚未生效的输入显示为已连通。关闭后旧请求不得更新页面，重新打开可正常检查；`SettingsRemoteStatusTests` 和导航释放回归源码尚未执行。

登录尚未完成时关闭并重开设置，成功或失败后新页面应反映当前共享身份，旧页不得回写状态。正常刷新等待 UserInfo 时保持登录状态，验证失败后显示退出；退出应在提供方返回前反映本地会话已清除。页面释放后，已投递的通知不得继续更新旧页。`SettingsAuthenticationLifetimeTests` 为受控回归源码，真实浏览器登录、凭据库和 IdP 仍需验收。

创建备份先核对包含项、估算大小和排除项；未确认时目标和临时文件均不产生，生产确认只在真正创建出现。确认前占用目标应安全拒绝；关闭页面或迟到文件选择器不得启动旧预览。压缩中取消清理本次临时文件，已发布后取消不撤回；压缩比例达到 100% 后仍可能需要归档收尾及发布。最小窗口、中英文和三档密度下，通过滚动可访问全部预览和确认按钮。`BackupProgressTests` 及新增 `BackupTests` 为回归源码，尚无运行或截图证据。

使用隔离数据目录分别放入未来版本的 settings 和 workspace（含未知根版本、布局版本），确认整份原件保留 `.unsupported`、默认启动且不丢弃原内容。预先占用保留副本名，确认后续设置／布局保存被阻止，已有副本和原件均不覆盖；损坏文件核对 `.bad`。恢复包中的未知版本应被拒绝，不按默认值导入。

新增 `SidePanelTests`、工作区偏好与导航测试覆盖以下行为；测试源码尚未编译执行。Windows 手动验收仍需保留实际结果：

## 日志分类与授权

窗口关闭另需验收：未保存确认挂起时重复关闭不得重复确认；期间替换工作区或换出再换回，旧确认的允许／拒绝／异常均不得自动关闭窗口或覆盖当前状态。替换后的工作区再次关闭时必须执行自己的确认，拒绝保留窗口和页面，允许后只关闭、释放一次。`WorkspaceNavigationTests` 新增六个参数场景，尚未执行 C#；旧工作区已开始的预检不承诺撤回。

写时脱敏另需检查真实 NDJSON，而不只检查日志页：使用模拟凭据、邮箱、路径、业务编码和嵌套正文触发日志，确认被屏蔽或丢弃；异常只包含类型与不含机器路径的有界方法调用帧。校验新旧审计分类、GUID 字符串及远程 `server-operation-1` 等合法关联 ID 仍可过滤定位，trace/span 可保留。禁止向消息模板或白名单字段塞业务正文；源码插值门禁不能替代这一约束。`RedactingLogSinkTests` 为回归源码，当前未执行。

恢复取消需使用独立数据目录：分别在复制、校验和解压期间取消，确认任务为取消、源备份及旧 pending 保留、本次临时内容清理；没有旧 pending 时取消不得新增待恢复包。发布成功后再取消应保持成功，下次启动仍恢复已发布的包，不能据取消按钮声称已回滚。`BackupTests` 包含受控流与任务终态回归源码，Windows 文件占用及真实重启恢复仍待实测。

恢复预览的清单和确认哈希必须来自同一私有快照；预览后把所选路径替换为另一份有效包，确认应拒绝且保留旧 pending。Linux 专项覆盖源路径重命名替换，Windows 按实际共享限制记录行为。验证源目录只读但数据目录可写时可预览；预览完成、复制中取消和坏包失败后，数据目录不残留本次 `.restore-preview-*` 内容。磁盘不足时应安全失败，不创建待恢复包。`BackupRestorePreviewTests` 提供五项回归源码，尚未运行。

## IME 实测

列表上下文菜单另需验收：右键另一行时，分别选择保存、丢弃、取消，核对目标行、表单、菜单与最终删除对象一致；保存导致列表刷新后弹层仍可见。右键表头或空白处不得操作旧选择。表格获得焦点时，用 Shift+F10／系统菜单键打开菜单，方向键、Enter 和 Escape 可用；编辑进入表单，复制内容来自目标记录，删除必须二次确认。查询、保存和未保存确认期间不可触发记录操作，认证启用且权限不足时禁用编辑／删除，服务入口仍拒绝未授权写入。换页或更换数据上下文时关闭菜单。`DemoContextMenuTests` 为新增测试源码，目前未执行；Windows 菜单位置、焦点恢复和剪贴板需实测。

日志与错误中心另需验收：先设不匹配的日期／等级／搜索条件，再从意外错误弹窗打开关联日志，确认旧条件被替换；从任务中心查看任务日志，确认信息级开始／完成记录与错误记录均可见。重复跳转复用日志标签，Ctrl+F 聚焦搜索，清空筛选后恢复无条件的技术日志查询；需要任务事件时切换类别。快速连续切换查询时旧结果与旧详情不得覆盖新查询；无匹配记录有空结果提示。最小窗口、右栏展开、中英文及三档密度下，操作栏和日期栏换行后仍可操作。新增 `LogNavigationTests` 为测试源码，当前无执行证据。

使用 Windows 微软拼音，在示例编码、名称、备注和日志搜索中输入中文、英文、数字、全角标点与混合文本。测试组合态候选窗、选词、退格、光标移动、跨字段 Tab、粘贴、多行换行和最大长度边界。

## Windows UIA 与读屏实测

使用 Accessibility Insights for Windows 或 Inspect 查看 UIA 树，再用 Narrator 实际操作；产品要求兼容 NVDA 时补测并记录版本。

- 页面输入和选择控件具有明确的本地化名称、角色、值、状态；文本标签应与输入建立正确关联，不能仅靠占位文字或 Tooltip。日志筛选框、日期范围、只读详情、设置数值项和示例排序/页大小需要逐项确认。
- 标签宣布名称、选中状态，关闭按钮宣布关闭意图及所属完整标题，不能只读“叉号”。图标按钮、菜单与工具栏名称可区分。
- 表格宣布表名、列头、当前行列、选中状态和单元格值；空列表应有可理解反馈。检查键盘行选择与进入编辑表单，不能仅凭表格本身有 Name 判通过。
- 错误、加载、保存成功/失败、未保存与删除/恢复确认信息可被读屏感知；弹窗有标题、初始焦点、受控焦点范围及关闭后的焦点恢复。
- 焦点移动时名称和值与画面一致，中英切换后没有资源键泄漏或遗留错误语言。头部 Name 检查通过也不能代替 Windows UIA 桥和实际朗读。
